# User API Search

A simple JavaScript application that fetches user data from a REST API and allows users to search and view user information.

## Features

- Fetch users from a REST API
- Display user information dynamically
- Search users by name, username, and email
- View individual user details
- Close user details
- Loading message while fetching data
- Error handling for failed API requests

## Technologies Used

- HTML
- CSS
- JavaScript
- REST API
- Fetch API
- Async/Await

## API

This project uses JSONPlaceholder Users API for sample user data.
